# Internationalization

- Languages: **简体中文 (`zh-CN`)** (default) and **English (`en`)**.
- Locale files: `apps/desktop/src/locales/{zh-CN,en}.ts`.
- Runtime switch: Settings → Application → Language (persisted in `config.json`).

## Adding a language

1. Copy `src/locales/en.ts` to `src/locales/<locale>.ts`.
2. Translate every key; do not remove keys.
3. Register the locale in `src/locales/index.ts` and in `availableLocales`.
4. Run `pnpm --filter @originium/desktop typecheck` and the unit tests.

## Rules

- Keys are grouped by feature (`nav`, `local`, `hosts`, `session`, `settings`, …).
- Parameters use vue-i18n named interpolation.
- Keep key parity between languages; a missing key falls back to English.
